Cinco landings con el mismo contenido y una identidad distinta cada una. Elige una (o mezcla lo mejor de varias) y la dejamos lista para publicar.

  1. 01Rally

    Una pantalla, un mini-juego de pádel y dos colores. Cada punto al bug desbloquea un capítulo.

  2. 02Render

    Fanzine risográfico a dos tintas. Un interruptor enseña la página como plantilla Smarty.

  3. 03Manual de montaje

    Instrucciones para montar un desarrollador: piezas, pasos y un dibujo que se monta al bajar.

  4. 04Carta de tintas

    Un abanico de muestras de color que se despliega arrastrando. Cada tinta es una parte de ti.

  5. 05mate0s FM

    Una radio de diseño industrial: gira la rueda para sintonizar cada sección. Entre emisoras, estática.
